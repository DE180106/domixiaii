3. What is inheritance?
Answer: B. A mechanism for sharing and reusing code between classes
-----

3. What is reusability?
Answer: B. The extent to which software is capable of being reused
-----

3. What is scalability?
Answer: B. The extent to which the system is capable of growing after its initial deployment
-----

3. What is testability?
Answer: B. The extent to which software is capable of being tested before deployment
-----

3. What is modifiability?
Answer: C. The extent to which software is capable of being modified during and after initial development
-----

3. What is maintainability?
Answer: B. The extent to which software is capable of being changed after deployment

Answer: A. One state with a different transition out of it for each incoming message
