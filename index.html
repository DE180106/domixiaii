Study Notes

Software Modeling Q&A

A clean reading page for the question and answer text. 

1. What is software modeling?
Answer: B. Designing software applications before coding.
-----

2. What is the Unified Modeling Language?
Answer: D. A standardized graphical language and notation for describing object-oriented models.
-----

3. What is a software architecture?
Answer: C. The overall structure of a software system.
-----

4. What is a software design notation?
Answer: B. A graphical or textual description of the software.
-----

5. What is a software design concept?
Answer: C. A fundamental idea that can be applied to designing a system.
-----

6. What is a software design strategy?
Answer: D. An overall plan and direction for developing a design.
-----

7. What are software structuring criteria?
Answer: C. Guidelines used to help in structuring a software system into its components.
-----

8. What is a software design method?
Answer: A. A systematic approach for producing a design.
-----

9. What is a platform-independent model (PIM)?
Answer: B. A precise model of the software architecture before a commitment is made to a specific platform.
-----

10. What is a platform-specific model (PSM)?
Answer: C. A precise model of the software architecture mapped to a specific platform.
-----

11. How is an actor depicted on a use case diagram?
Answer: B. A stick figure
-----

12. How is a use case depicted on a use case diagram?
Answer: A. An oval
-----

13. How is a class depicted on a class diagram?
Answer: C. A box with one, two, or three compartments
-----

14. How is an association depicted on a class diagram?
Answer: A. A solid line joining two class boxes
-----

15. How is public visibility depicted for a class element on a class diagram?
Answer: A. + sign
-----

16. What are the two kinds of UML interaction diagrams?
Answer: B. Sequence diagram and communication diagram
-----

17. What does an interaction diagram depict?
Answer: C. Objects and messages
-----

18. What does a statechart diagram depict?
Answer: D. States and events
-----

19. What is a UML package?
Answer: D. A grouping of model elements
-----

20. What does a deployment diagram depict?
Answer: C. The physical configuration of the system in terms of physical nodes and physical connections between the nodes
-----

21. What is a software life cycle?
Answer: C. A phased approach to developing software
-----

22. What is the waterfall life cycle model?
Answer: B. A process model in which each phase is completed before the next phase is started
-----

23. Which of the following is a limitation of the waterfall life cycle model?
Answer: D. Software requirements are not properly tested until a working system is available.
-----

24. Which of the following approaches can overcome the limitation in the previous question?
Answer: B. Throwaway prototyping
-----

25. What is evolutionary prototyping?
Answer: D. Incremental development
-----

26. What approach does the spiral model emphasize?
Answer: C. Risk-driven development
-----

27. What is the goal of software validation?
Answer: B. Building the right system
-----

28. What is the goal of software verification?
Answer: C. Building the system right
-----

29. What is "white box" testing?
Answer: C. Testing with knowledge of the system internals
-----

30. What is "black box" testing?
Answer: D. Testing without knowledge of the software internals
-----

31. Which of the following are object-oriented concepts?
Answer: C. Classes, information hiding, and inheritance
-----

32. Which of the following is a characteristic of an object?
Answer: C. Groups data and procedures that operate on the data
-----

33. What is a class?
Answer: C. A collection of objects with the same characteristics
-----

34. What is an operation, also known as method, of a class?
Answer: C. Specification and the implementation of a function or procedure provided by a class
-----

35. What is the signature of an operation?
Answer: C. The operation's name, parameters, and return value
-----

36. What is the interface of a class?
Answer: B. The specification of operations provided by the class
-----

37. What is an attribute?
Answer: C. A data item held by a class
-----

38. What is information hiding in software design?
Answer: B. Hiding a design decision that is considered likely to change
-----

39. What is data abstraction?
Answer: B. Encapsulating data so that its structure is hidden
-----

40. What is inheritance?
Answer: B. A mechanism for sharing and reusing code between classes
-----

41. What is carried out during requirements modeling?
Answer: B. Functional requirements of the system are described in terms of actors and use cases.
-----

42. What is carried out during analysis modeling?
Answer: C. Developing static and dynamic models
-----

43. What is carried out during design modeling?
Answer: D. Developing software architectures
-----

44. What is carried out during incremental software construction?
Answer: B. Detailed design, coding, and unit testing of the classes in a subset of the system
-----

45. What is carried out during incremental software integration?
Answer: C. Integration testing of the classes in each software increment
-----

46. What is carried out during system testing?
Answer: B. Black box testing
-----

47. What is a use case?
Answer: C. A sequence of interactions between the user and the objects in the system
-----

48. What is an actor in a use case?
Answer: C. An external entity that interacts with the system
-----

49. What is a primary actor?
Answer: B. The actor that starts the use case
-----

50. What is a secondary actor?
Answer: C. An actor that participates in the use case
-----

51. What is an alternative sequence in a use case?
Answer: B. A sequence that is different from the main sequence
-----

52. What can an inclusion use case be used for?
Answer: C. To describe functionality that is common to more than one use case
-----

53. What can an extension use case be used for?
Answer: D. To describe a conditional part of a different use case that is only executed under certain circumstances
-----

54. What can an activity diagram be used for in use case modeling?
Answer: D. To depict the activities in the main and alternative sequences of a use case
-----

55. How can a non-functional requirement be described in a use case model?
Answer: A. In a separate section of the use case description
-----

56. What is a use case package?
Answer: C. A group of related use cases
-----

57. What is a class?
Answer: D. A collection of objects with the same characteristics
-----

58. What is an attribute?
Answer: C. A data value held by an object in a class
-----

59. What is an association?
Answer: A. A relationship between two classes
-----

60. What is meant by the multiplicity of an association?
Answer: D. How many instances of one class relate to a single instance of another class
-----

61. What is an association class?
Answer: C. A class that models an association between two or more classes
-----

62. What is a generalization/specialization hierarchy?
Answer: B. An inheritance relationship
-----

63. What is a composition hierarchy?
Answer: D. A strong form of a whole/part relationship
-----

64. What is an aggregation hierarchy?
Answer: C. A weak form of a whole/part relationship
-----

65. What does the system context class diagram define?
Answer: C. The boundary between the system and the external environment
-----

66. What is an entity class?
Answer: B. A class that stores data
-----

67. What is a boundary object?
Answer: C. An object that communicates with an external object
-----

68. What is a control object?
Answer: C. An object that controls other objects
-----

69. What is a state-dependent control object?
Answer: D. An object that executes a state machine
-----

70. What is a coordinator object?
Answer: C. A decision-making object
-----

71. How would you determine a boundary class from the context diagram?
Answer: C. By determining the software classes that communicate with the external classes
-----

72. What is a timer object?
Answer: C. An object that is awakened by an external timer
-----

73. What do class structuring criteria help with?
Answer: A. Structuring an application into classes
-----

74. What is the classification process for application classes analogous to?
Answer: A. Categorizing books in a library
-----

75. What is the purpose of a stereotype in class structuring?
Answer: A. To label a class according to its class structuring criterion
-----

76. What is a business logic object?
Answer: B. An object that defines business-specific application logic
-----

77. What does an interaction diagram depict?
Answer: C. Software objects and the sequence of their interactions
-----

78. How is an actor depicted on an interaction diagram?
Answer: D. An instance of an actor can provide input to or receive output from a boundary object.
-----

79. What does a sequence diagram depict?
Answer: C. Software objects and the sequence of their interactions
-----

80. What does a communication diagram depict?
Answer: C. Software objects and the sequence of their interactions
-----

81. What is the instance form of an interaction diagram?
Answer: B. Depicts one possible sequence of interactions among object instances
-----

82. What is the generic form of an interaction diagram?
Answer: C. Depicts all possible interactions among objects
-----

83. During dynamic interaction modeling, use cases are realized as follows:
Answer: A. Determine objects that participate in each use case and the sequence of interactions among them.
-----

84. Which of the following interactions could happen on an interaction diagram?
Answer: A. An external user sends a message to a user interaction object.
-----

85. Which of the following interactions is NOT likely to happen on an interaction diagram?
Answer: C. An input object sends a message to a printer object.
-----

86. What kind of object would be the first object to receive an input from an external object?
Answer: D. A boundary object
-----

87. What is a state in a state machine?
Answer: A. A recognizable situation that exists over an interval of time
-----

88. What is an event in a state machine?
Answer: A. A discrete signal that causes a change of state
-----

89. What is an action in a state machine?
Answer: D. A computation that executes as a result of a state transition
-----

90. What is an entry action in a state machine?
Answer: A. An action that is performed when the state is entered
-----

91. What is an exit action in a state machine?
Answer: B. An action that is performed when the state is left
-----

92. What is a condition used for in a state machine?
Answer: C. A conditional state transition
-----

93. What is a state transition into a composite state equivalent to?
Answer: A. A transition into only one of the substates
-----

94. What is a state transition out of a composite state equivalent to?
Answer: B. A transition out of each of the substates
-----

95. How does a composite state relate to a substate?
Answer: A. A composite state is decomposed into substates.
-----

96. If two actions are shown on a given state transition, which of the following is true?
Answer: B. The two actions are independent of each other.
-----

97. What does a state-dependent interaction involve?
Answer: C. A state-dependent control object
-----

98. Which kind of object executes a state machine?
Answer: C. A state-dependent control object
-----

99. An input message to a state-dependent control object corresponds to:
Answer: A. An event on the internal state machine
-----

100. An output message from a state-dependent control object corresponds to:
Answer: B. An action on the internal state machine
-----

101. An interaction diagram should be developed for:
Answer: B. The main sequence and every alternative sequence of the use case
-----

102. Which of the following could happen on an interaction diagram?
Answer: D. All of the above.
-----

103. If the same state machine is used in more than one use case, how is this modeled on interaction diagrams?
Answer: B. Develop one state-dependent control object containing states from each use case.
-----

104. How would two state-dependent control objects communicate with each other?
Answer: A. By sending messages to each other
-----

105. An object can send alternative messages a or b to a state-dependent control object. How is this handled in the state machine?
Answer: A. One state with a different transition out of it for each incoming message
-----

106. In a system in which a client object executes a state machine and communicates with a service, which of the following is true?
Answer: A. The client has a state-dependent control object but the service does not.
-----

107. What do software quality attributes address?
Answer: B. Software nonfunctional requirements
-----

108. What is maintainability?
Answer: B. The extent to which software is capable of being changed after deployment
-----

109. What is modifiability?
Answer: C. The extent to which software is capable of being modified during and after initial development
-----

110. What is testability?
Answer: B. The extent to which software is capable of being tested before deployment
-----

111. Traceability is the extent to which a product:
Answer: A. Can be traced back to products of previous phases
-----

112. What is scalability?
Answer: B. The extent to which the system is capable of growing after its initial deployment
-----

113. What is reusability?
Answer: B. The extent to which software is capable of being reused
-----

114. Which of the following is not performance-related?
Answer: C. System availability
-----

115. Which of the following is not addressed by a secure system?
Answer: C. System scalability
-----

116. Which of the following system problems does availability address?
Answer: B. Single point of failure
-----
